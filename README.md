# 吃什麼？Food Pocket

一個以 `AGENTS.md` 規範開發的個人美食口袋名單網站，透過統一的開發規則，讓 AI 能夠協助持續新增餐廳資料及維護網站。

## 專案介紹

Food Pocket 是一個個人美食收藏網站，提供餐廳資訊整理、搜尋及篩選功能，讓使用者可以快速找到感興趣的餐廳。

本專案使用 HTML、CSS 與 JavaScript 開發，並透過 GitHub Pages 部署，不需要額外的伺服器或資料庫。

專案的主要特色是建立 `AGENTS.md`，規範 AI 修改網站時應遵守的資料格式、檔案位置、命名方式及測試流程，使網站能夠持續擴充。

## 網站功能

- 餐廳卡片展示與詳細介紹彈出視窗
- 關鍵字搜尋餐廳
- 料理類型與地區篩選
- 響應式網頁設計，支援手機與電腦瀏覽
- 支援使用 Escape 鍵關閉詳細介紹視窗
- 餐廳資料與網站版型分離，方便新增及維護

## AI 新增內容流程

當需要新增餐廳時，AI 應依照以下流程進行：

1. 先閱讀 `AGENTS.md`，了解網站開發規則。
2. 檢查 `assets/js/restaurants.js` 中既有的餐廳資料。
3. 按照既定資料格式新增餐廳，確認 ID 不重複。
4. 保留原有餐廳資料，避免不必要的修改。
5. 確認搜尋、料理類型篩選、地區篩選及詳細介紹視窗正常運作。
6. 說明修改的檔案及測試結果。

## AGENTS.md 實際驗證

本專案最初建立三筆示範餐廳資料，並於後續開發過程中，新增真實餐廳「Ariel Lee 李氏．Cafe」作為第四筆資料。

AI 依照既有資料結構新增餐廳，保留原本三家餐廳，並調整真實餐廳與示範資料的顯示方式。

更新程式碼並部署至 GitHub Pages 後，網站成功顯示四家餐廳。經實際測試，關鍵字搜尋及餐廳詳細介紹功能均可正常使用。

此過程展示 `AGENTS.md` 如何協助 AI 遵守既有規範，持續擴充網站內容，並維持網站架構與設計的一致性。

## 使用方式

可直接在瀏覽器開啟 `index.html`，或透過 GitHub Pages 公開網址使用網站。

GitHub Pages 部署設定：

- Branch：`main`
- Folder：`/ (root)`

## 資料說明

網站同時包含示範餐廳與真實餐廳資料。

- 示範餐廳：名稱、價格、推薦餐點及心得均為虛構，僅用於功能展示。
- 真實餐廳：使用真實餐廳名稱及相關資訊，尚未確認的價格、推薦餐點與個人心得不任意編造。
- 未使用外部圖片，餐廳卡片以內建 emoji 插畫作為佔位。

本網站為課堂作業與個人學習用途，餐廳資訊僅供參考。
