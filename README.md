# 吃什麼？Food Pocket

一個以 `AGENTS.md` 規範開發的個人美食收藏示範網站。

## 功能
- 餐廳卡片與詳細介紹彈出視窗
- 關鍵字搜尋、料理類型及地區篩選
- 響應式設計、鍵盤 Escape 關閉視窗
- 資料與版型分離，便於擴充

## 使用方式
在瀏覽器開啟 `index.html` 即可。部署至 GitHub Pages 時，使用 `main` 分支與 `/ (root)`。

## AI 新增內容流程
先閱讀 `AGENTS.md`，再於 `assets/js/restaurants.js` 增加資料。請先檢查 ID 唯一、必要欄位完整，並驗證搜尋、分類與詳細視窗。初版僅三筆示範資料，第四筆保留作為課堂規則驗證。

## 注意
所有示範餐廳、價格及心得均為虛構，不構成真實推薦。未使用外部圖片，使用內建 emoji 插畫佔位。
